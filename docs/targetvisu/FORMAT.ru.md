# Контракт TargetVisu JSON, версия 1

Нормативная схема: src/middleware/shared/targetvisu/model.ts.
Координаты, размеры и fontSize задаются в логических пикселях экрана.
Масштаб Editor — состояние интерфейса и не меняет сохраняемые координаты.

Корень:

- version: 1; target: "native-x11".
- refreshMs: 100..5000 мс, предполагаемый период обновления значений клиента.
- startScreen: UUID стартового экрана; пустая строка при отсутствии экранов.
- screens: массив экранов. У каждого id, name, width, height, background, grid,
  elements. Фон и цвета элементов — #RRGGBB; имя экрана уникально без учёта регистра.

Элемент:

- id, name и kind: rectangle / ellipse / line / text / indicator / button / number.
- x, y, width, height: ограничивающий прямоугольник. Элемент полностью внутри экрана.
- lineDirection: horizontal / vertical / diagonal-down / diagonal-up.
  Для horizontal линия по центру высоты прямоугольника, для vertical — по центру
  ширины; диагонали соединяют соответствующие углы. Для остальных видов поле
  игнорируется. Все семь видов используют одинаковую геометрическую структуру.
- fill, activeFill, stroke, strokeWidth, textColor, fontSize, text.
- decimals, minimum, maximum: формат и диапазон числового поля.
- bindings: value, visible, enabled. Пустая строка означает отсутствие привязки.
- action: kind (none/set/toggle/momentary/write), target, value (boolean/number/string).

elements отсортирован от заднего к переднему слою. Текст центрируется и обрезается
по прямоугольнику элемента. Текстовый элемент с value отображает значение переменной;
иначе — text. Числовое поле отображает value с decimals, отсутствие данных — тире.
Indicator выбирает activeFill только для BOOL TRUE. visible/enabled трактуются
как BOOL TRUE; отсутствие привязки означает видимый/доступный элемент.

Имена переменных регистронезависимы, представлены символическими путями. В файле
нет указателей, адресов процесса или привязки к порядку debug-переменных. Разрешение
символов и подтверждение соответствия загруженной программе — задача будущего Runtime.
Действие write относится к number; конкретное введённое значение поступает от
клиента и ограничивается диапазоном и типом переменной. value в описании write
не считается командой при загрузке файла.

Формат описывает экраны. Он не является реализацией исполнительного клиента.
Менять несовместимую структуру следует с увеличением version и явной миграцией.

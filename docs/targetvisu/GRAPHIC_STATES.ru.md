# Graphic View — смена изображений от PLC-переменной

Начиная с ветки `feature/graphic-view-image-states` примитив **Graphic View**
поддерживает до 16 состояний изображения по значениям PLC.

1. Добавьте `Graphic View` на экран TargetVisu.
2. В **Image selector variable** выберите `BOOL` или целочисленную PLC-переменную
   (`SINT`, `INT`, `DINT`, `USINT`, `UINT`, `UDINT`, `BYTE`, `WORD`, `DWORD`).
3. В **Image states** выберите **Добавить изображение для значения PLC** и загрузите
   PNG/JPEG. Для каждого состояния укажите значение переменной (без повторов).
4. При необходимости загрузите **Default image** — она появится при неизвестном
   значении переменной или потере данных PLC.
5. Выберите **Graphic fit**. В Preview меняйте значение переменной и проверьте
   переключение изображений.
6. Сохраните, соберите и загрузите проект на устройство с обновлённым Runtime.

Пример Structured Text:

```iecst
VAR_GLOBAL
    CompressorState : INT := 0;
END_VAR
```

Назначьте графику `Image selector variable = CompressorState`:
- `0` — остановлен;
- `1` — работает;
- `2` — авария.

Важные правила:
- Для BOOL используйте значения 0 (FALSE) и 1 (TRUE).
- Неизвестное значение не считается ближайшим: требуется точное совпадение.
- Если привязки нет, используется статическая картинка (или первая в списке,
  если статической картинки нет). Если значение неизвестно, используется
  только Default image, иначе серая заглушка.
- Для статического Graphic View по-прежнему достаточно одного PNG.
- Изображения встроены в проект, не передаются отдельными файлами.
- Максимум 16 состояний, до 1024×1024 пикселей и 1 МиБ PNG каждое;
  общий лимит TargetVisu JSON 4 МиБ.
- Графика не отправляет команд на PLC; для управления используйте Button.

Для обновления Python Runtime на Banana Pi см. [TargetVisu v0.7.0](https://github.com/Alexmoto/openplc-runtime/blob/feature/graphic-view-image-states/updates/targetvisu-graphic-v0.7.0/README.ru.md).

## Разработка

Изменения включают схему `graphic.variants`, визуальную панель управления,
проверку типа переменной и передачу привязки в Runtime. Основа — ветка
`feature/number-dynamic-colors`; до слияния её изменений оба PR следует
рассматривать как последовательные (stacked) обновления.

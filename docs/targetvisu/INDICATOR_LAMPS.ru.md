# Индикатор: 12 объёмных ламп по числовому значению PLC

В TargetVisu Editor добавлено новое оформление примитива **Indicator**,
сохраняющее размеры и блики присланной лампы `Lamp33x33Off.png`.

В свойствах Indicator выберите **Indicator style**:

- **Classic (BOOL)** — привычный двухцветный индикатор для `BOOL`.
  У старых проектов он останется прежним.
- **12-color lamp (0 = hidden)** — цифровая палитра на основе исходного PNG,
  выбор одной из двенадцати ламп по текущему значению `Value variable`.

Для новой палитры:
- 0 — ничего не нарисовано, индикатор скрыт целиком;
- 1 — светло-серый, 2 — темно-серый;
- 3 — светло-зелёный, 4 — темно-зелёный;
- 5 — светло-красный, 6 — темно-красный;
- 7 — светло-жёлтый, 8 — темно-жёлтый;
- 9 — светло-оранжевый, 10 — темно-оранжевый;
- 11 — светло-синий, 12 — темно-синий.

Остальные значения и отсутствие данных тоже дают невидимый индикатор.

Связывайте `Value variable` с `SINT/USINT/BYTE/INT/UINT/WORD/DINT/UDINT/DWORD`.
Для режима 12-color lamp переменная должна иметь целочисленный тип,
в отличие от прежнего Classic BOOL.

Пример Structured Text:

```iecst
VAR_GLOBAL
    AlarmColor : UINT := 0;
END_VAR
```

Для Preview откройте экран и измените значение `AlarmColor` в правой панели
от 0 до 12. Изображения в Editor и на Banana Pi одинаковые: используется
встроенный компактный спрайт-атлас 396×33, а не отдельные файлы в PLC.
Индикатор масштабируется пропорционально и центрируется в прямоугольнике.

Для установки новых Python-модулей на Banana Pi используйте
[TargetVisu v1.1](https://github.com/Alexmoto/openplc-runtime/blob/feature/indicator-lamp12/updates/targetvisu-lamps-v1.1.0/README.ru.md).

Ветка `feature/indicator-lamp12` включает все предыдущие функции TargetVisu.
Не объединена с `main` до проверки реального оборудования.

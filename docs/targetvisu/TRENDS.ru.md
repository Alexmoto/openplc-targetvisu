# Тренды TargetVisu

Новый графический элемент **Trend** для отображения истории числовых переменных
PLC на экране X11/GTK OpenPLC Runtime. В Editor тренд добавляется в разделе
**Primitives → + Trend**.

## Параметры

- **History window**: 1, 5, 15, 30 или 60 минут.
- **Sample period**: 0,5 / 1 / 2 / 5 / 10 / 30 / 60 секунд.
- **Auto scale Y**: автоматическая шкала значений; если выключено, применяются
  поля **Minimum** и **Maximum** элемента.
- **+ Add curve**: до 4 числовых переменных, свой цвет и подпись легенды.
- Максимум 8 графиков на проект, не больше 600 отсчётов на график.

При увеличении временного окна Editor автоматически подбирает допустимый
интервал записи для ограничения числа точек. Нельзя использовать BOOL, неизвестные
переменные и повторно назначать одну переменную двум кривым одного тренда.

Редактор показывает демонстрационный график с подписью
`Preview • no PLC history`. **Настоящие значения появляются только
в Runtime** после загрузки проекта и запуска обновлённого TargetVisu.

Привязки тренда попадают в тот же debug-map, что и остальные визуальные
элементы. Визуализация только считывает значения и не предоставляет доступ
на запись в PLC. Переменные могут обновляться внутренней логикой, Modbus или MQTT.

Сейчас история хранится только в оперативной памяти сервиса TargetVisu, а не
в архивном файле: перезапуск сервиса очищает буфер. Данные отображаются в
скользящем временном окне; масштабирование по времени/CSV/архив на диске
в эту первую версию не входят.
